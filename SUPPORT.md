# Support

Start with the [README](README.md), especially its requirements, installation,
and migration sequence. This Beta has no separate usage-question forum.

Use [GitHub Issues](https://github.com/RocketsAreNostalgic/ran-booster-wp-pusher-migrator/issues)
for reproducible, non-sensitive defects in the latest Beta release. Before
opening an issue, check for an existing report and include:

- the exact WordPress, PHP, RAN Booster, Migrator, and WP Pusher versions;
- whether the affected package is a plugin or theme;
- the provider and whether the repository is public or private;
- concise reproduction steps, expected behavior, and observed behavior; and
- the checks already performed.

Redact private repository names when needed. Never post credentials, WordPress
salts, database contents, signed URLs, customer data, or full production logs.

Security reports belong in the confidential channel described in
[SECURITY.md](SECURITY.md), not in Issues. Reports are reviewed as maintainer
capacity permits; no response or resolution time is guaranteed.
