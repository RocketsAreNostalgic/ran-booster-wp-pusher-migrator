# Security

Only the latest Beta release is supported. Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/RocketsAreNostalgic/ran-booster-wp-pusher-migrator/security/advisories/new).
Do not include provider credentials, WordPress salts, database contents, signed
URLs, or production log extracts in a public issue.

If private reporting is unavailable, use the [issue chooser](https://github.com/RocketsAreNostalgic/ran-booster-wp-pusher-migrator/issues/new/choose)
and select `Security reporting help` only to request a confidential contact route.
Include no vulnerability details, exploit steps or reproduction traces in that public request.

Private migration reports should identify the WordPress, PHP, RAN Booster, bridge, and
WP Pusher versions plus the affected package type and provider. In public issues and pull requests, always replace private repository and site
identities with neutral labels; do not publish private material for reproduction.

Public issues and pull requests are not confidential security channels. This
policy does not promise an acknowledgment or resolution time.
