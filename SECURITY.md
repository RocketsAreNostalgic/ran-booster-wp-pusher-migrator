# Security

Only the latest Alpha release is supported. Report vulnerabilities through the
repository's private vulnerability-reporting channel. Do not include provider
credentials, WordPress salts, database contents, signed URLs, or production log
extracts in a public issue.

Migration reports should identify the WordPress, PHP, RAN Booster, bridge, and
WP Pusher versions plus the affected package type and provider. Redact
repository names when their disclosure is sensitive.
